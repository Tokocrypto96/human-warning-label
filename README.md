## The entry

> WARNING: This human forms strong opinions about things it learned five minutes ago and will defend them forever.

One line, 112 characters. Funny first, plausible second: a safety warning label that should come printed on every human being.

## How it works

`main.ts` writes the label to `/output/entry.txt` (Node 22+). It validates the gate first: 1–160 characters, a single line, not blank.

```sh
node main.ts
```
